# 易の余白 — AI易経アプリ

三千年の易経を、現代の自分を見つめるための問いとして体験する日本語Webアプリです。note記事のコンセプトをもとに、64卦の算出・コイン法・筮竹法・変爻と之卦・日本語の解釈画面を、最初から動く一つのアプリにまとめています。

> 大切なお知らせ：易経の結果は自己省察のための参考情報です。未来を保証するものではなく、医療・法律・金融その他の専門的助言の代わりにはなりません。最終的な判断はご自身で行ってください。

## 必要な環境

- Node.js 20.9以降（Node.js 22推奨）
- npm
- AI解釈を使う場合はAnthropic APIキー（任意）

## ローカルで起動

```bash
npm install
cp .env.example .env.local
npm run dev
```

ブラウザーで `http://localhost:3000` を開きます。APIキーなしでも、コイン法・筮竹法、64卦算出、変爻・之卦、結果表示と共有が動作します。AI解釈も有効にするには `.env.local` に `ANTHROPIC_API_KEY=your_key_here` を記入してサーバーを再起動してください。キーはサーバーだけで使用し、ブラウザーに公開しません。

## 機能

- 3枚コインを6回投げる操作で本卦・変爻・之卦を算出
- 筮竹法（大衍法）のデジタルシミュレーション
- 文王卦序に基づく64卦すべてのパターン検索
- 八卦・卦辞・爻の段階に応じた日本語解釈
- 任意のAnthropic APIによる質問に沿った追加解釈（API不調時はローカル解釈に自動でフォールバック）
- 64卦一覧、今日のことば、結果共有、モバイル対応

## 検証

```bash
npm run verify
npm run build
npm run lint
```

## 公開

GitHubで公開リポジトリを作成し、このフォルダで以下を実行します。

```bash
git init
git add .
git commit -m "Build Japanese I Ching reading app"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/iching-ai-app.git
git push -u origin main
```

Vercelなどのホスティングへデプロイする場合、プロジェクトの環境変数に `ANTHROPIC_API_KEY` を登録してください。APIキーなしでも基本機能は利用できます。

## 実装上の注意

- 元記事のコードは途中省略があり、記載された卦対応表に上下卦の取り違えがあります。この実装は「初爻から上爻」の陰陽パターンを64卦の標準的な文王卦序に照合します。
- 記事にある64卦の個別解説は一部のみです。本プロジェクトは全64卦を完全な名称・卦番号・爻パターンで扱い、すべての卦に汎用の日本語案内を用意しています。個々の卦辞・爻辞の完全な古典本文を収録したものではありません。
- 手書き認識API・LINE連携・課金は、記事中に動作可能な完全実装が示されていないため含めていません。
